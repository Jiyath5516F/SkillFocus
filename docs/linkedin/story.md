# How Mira was built (short story — edit freely)

10:55 AM. The problem statement landed: help students and employees see which skills they really lack for the career they want. I didn't want another chatbot with a course list, so the first hour was all about one idea: a completed course is a claim, not proof.

By 11:30 the plan was locked and the build started. Five specialised AI agents, each with its own job, and one rule: the AI explains, but the numbers come from a transparent formula.

At 11:40 the first real agent run worked end to end. By noon the core journey passed its acceptance tests: a learner fails a JavaScript quiz, their readiness drops from 28.8% to 21.2%, and the agents insert targeted practice before React.

Then came the hard part: making it feel like a real product. The organisers asked for secure accounts, so I added sign-up, hashed passwords and per-user data isolation. Internet issues earned everyone extra time, which I spent on the details: a setup wizard, a roadmap.sh-style learning map, a readiness forecast, and custom career aims where you type any goal and Mira designs the role.

By the end, Mira was live on its own domain with 45 automated tests.
